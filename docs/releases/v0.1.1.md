# v0.1.1

**The integration no longer stores your Amazon account's email address.**
Version 0.1.0 kept it in the config entry, as the entry's identifier and in its
title "Works with Alexa (email)". The entry now records the account only as a
one-way SHA-256 key of the email. The key still lets the integration recognise
the same account when you sign in again, and refuse a second setup of it. No
password was ever stored, and none is now.

- Existing entries are converted automatically the first time they load after
  the update. Your sign-in, devices, scenes and options are kept. A title you
  renamed is kept; the generated title becomes "Works with Alexa".
- A **disabled** entry is converted when you next enable it.
- Reauthentication no longer shows a polling-interval field that it ignored.
  Change the interval in the entry's Options.
- The bundled integration icons are refined.
- The README now describes what is stored, how setup and reauthentication work,
  and several entity and metadata details more accurately.

After updating, do not go back to 0.1.0. A converted entry still loads there,
but 0.1.0 cannot reauthenticate it.

Requires Home Assistant **2026.3.0 or newer**, unchanged. No new Python
requirements.
