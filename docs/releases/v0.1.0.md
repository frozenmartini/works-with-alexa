# v0.1.0 — first release draft

A Home Assistant integration for devices reachable through Amazon's unofficial
Alexa account API. Supported capabilities become raw switches, selects, numbers,
locks and sensors. Entity types follow advertised operations, options and bounds
regardless of manufacturer or accessory category.

- Sign in directly on Amazon in your own browser, then paste the final redirect
  URL into Home Assistant. Passwords and verification codes stay on Amazon.
  Setup and reauthentication verify the account before using the credentials;
  reauthentication keeps device and scene selections. Browser enrollment, phone
  2FA and subsequent refresh succeeded live in isolated validation.
- Select devices and scenes independently. Scenes default to unselected and
  appear as individual buttons under one Scenes device. Options supports adding,
  editing and removing selections without signing in again.
- Poll endpoints and paginated scenes every 60 seconds by default (15 minimum).
  Stateful controls update optimistically before requests, reconcile with polls,
  roll back failures without overwriting newer requests, and expire assumptions
  after 30 seconds.
- Development installations can enable rotating, redacted JSONL logs for API
  timings, acknowledgements, polling, refreshes, options and optimistic state.
- Optional `wwa_feature` metadata supports discovery by Kitbash through HA
  registries/state, preserving raw entity IDs, labels, commands, bounds and units.
- Credential persistence rejects writes from superseded or unloaded sessions.
  Recoverable CSRF renewal failures retry; confirmed root-token rejection requests
  reauthentication. Older serial-identified entries retain their IDs and selections,
  with verified account matching or explicit confirmation when no prior identity
  can be recovered.
- Bundled integration icons appear in Home Assistant without a separate brands
  repository submission. The provisional artwork can be updated in a later release.

Close Vanes activation was physically confirmed by the owner. Amazon's scene
response remains a placeholder acknowledgement, not completion confirmation.
Thermostat and lock writes remain unverified against physical devices; vacuum
control payloads remain unimplemented. Runtime polling, scheduled authentication
renewal and optimistic state confirmation have been observed after Core restarts.

Requires Home Assistant **2026.3.0 or newer** for bundled branding and the supported
configuration APIs. These notes are a draft; no release has been published.
