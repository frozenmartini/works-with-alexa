First release.

A Home Assistant integration for devices that only exist in Alexa — no native Home Assistant
integration, reachable only through Amazon's unofficial Alexa account API. Every device feature
Alexa reports becomes its own entity: switches, selects, numbers, locks and sensors, named and
bounded as Alexa names and bounds them.

- Four sign-in paths, including borrowing a token from Alexa Media Player.
- One bulk poll per interval (60 s default, 15 s minimum); optimistic writes that roll back on
  failure.
- Kohler devices are read-only by design, structurally, at every write path.

Requires Home Assistant 2024.6.0 or newer.
