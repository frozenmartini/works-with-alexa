# v0.1.4

**Documentation only: every device write is now verified from Home Assistant.**
No behaviour changes, no configuration changes and nothing to do after
updating.

- **Lock and unlock verified from Home Assistant.** With v0.1.3 installed, the
  lock entity locked and unlocked a Lockly smart lock: Amazon accepted both
  commands, the door actuated, and the next poll confirmed the state.
- **Docstrings and README match.** The number and select modules no longer
  describe thermostat writes as unexecuted, the lock module states what was
  verified, and the README's *What is verified* table records that lock/unlock
  and the thermostat were verified from Home Assistant. The vacuum row now says
  plainly that the integration reads vacuum status and sends no vacuum
  actions.
- **Scenes, options and capability mapping marked verified.** Their rows
  already described live results; they now say so, and state that
  overlapping-failure handling is verified by automated tests. Scene control
  is stated in general: a button runs the same scene the Alexa app runs, so
  any scene that works from the Alexa app works from its button.

Requires Home Assistant **2026.3.0 or newer**, unchanged. No new Python
requirements.
