# v0.1.2

**Fixes from a review of the whole integration.** No new features, no
configuration changes and nothing to do after updating.

- **Gentler retries against Amazon.** When scheduled sign-in renewal fails for
  a recoverable reason, such as a cookie problem, throttling or an Amazon
  outage, it now retries after a minute and then doubles the wait each time, up
  to an hour. It used to retry every minute for as long as the failure lasted,
  even while the entry was waiting for you to sign in again. A success returns
  it to the normal schedule. A rejected sign-in still asks you to sign in again
  at once.
- **A lock never shows as unlocked by mistake.** Only Alexa's explicit
  `UNLOCKED` now reads as unlocked. Any state the integration does not
  recognise reads as unknown instead.
- **Selected devices survive a gap at startup.** A device you selected that was
  briefly missing from Alexa's reply when Home Assistant started was removed,
  with its entities. Your selection now decides what is kept.
- **One warning per scene outage.** If scene discovery fails while devices keep
  working, the log gets one warning when scenes go away and one line when they
  return, instead of a warning on every poll.
- **Clean shutdown.** Stopping Home Assistant now stops the renewal timer on
  Home Assistant's event loop rather than from a worker thread.
- **YAML is reported as unsupported.** A `works_with_alexa:` key in
  `configuration.yaml` now produces Home Assistant's standard "does not support
  YAML setup" message instead of being ignored silently. Set the integration up
  from the UI, as before.

Requires Home Assistant **2026.3.0 or newer**, unchanged. No new Python
requirements.
