# v0.5.0

**Fixes devices that stopped updating in November 2026, signs in outside
amazon.com, and imports many more Alexa features.** Updating is recommended:
Amazon now refuses the app identity v0.1.4 sends, so v0.1.4 can no longer read
your devices.

## Fixes

- **Devices stopped updating (#8).** Amazon began refusing older Alexa app
  identities with a 403. Requests now send the current app's identity (#9,
  thanks @salvatore-081), and a refusal page from Amazon's edge fails one poll
  and retries at the next, instead of asking you to sign in again.
- **Sign-in outside amazon.com (#1).** Outside amazon.com the sign-in link
  opened an Amazon error page before any form. It now uses the sign-in form
  for your marketplace (#3, thanks @salvatore-081). Verified on amazon.it;
  other marketplaces are untested, so please report how yours goes.
- **Token refresh** no longer fails setup on a cookie Amazon sends with an
  invalid name.
- **Thermostat low and high setpoints:** setting one and then the other before
  the next poll no longer undoes the first.
- **A reply in which Amazon left out the device list** now fails that poll
  instead of reading as an account with no devices.

## New entities

Each new entity is one Alexa feature, as before, with Alexa's own fixed
ranges:

- Brightness, percentage and power level: a number, 0-100 (brightness and
  colour temperature started in #2, thanks @the-wozz).
- Colour temperature: a number, 1,000-10,000 K.
- Colour: three numbers, Color Hue (0-360), Color Saturation and Color
  Brightness (0-1), sent together.
- Motion: a binary sensor.
- Volume, illuminance, arm state and siren state: sensors.
- Thermostat setpoints use the device's allowed range when Alexa sends one,
  otherwise 40-120 °F, 5-50 °C or 278-323 K.

## Changes you may notice

- **Every value shows as Alexa reports it.** A number on a device that is off
  now reads the `0` Alexa reports instead of unknown. A switch is on for `ON`,
  off for `OFF`, and unknown for anything else.
- **Two new attributes on every device entity:** `alexa_value`, Alexa's last
  report for what the entity shows, and `alexa_reporters`, how the device
  reaches Alexa (`SKILL`, `AAA` or `ALEXABRIDGE`).
- **Discovery hints** (`wwa_feature.role`) now also tag brightness, colour
  temperature, hue, saturation, motion, and a thermostat's heating and
  cooling setpoints.
- Sensors no longer carry the `feature` attribute; `wwa_feature` has the same
  information.
- Starting a second sign-in for the same account no longer fails with "already
  in progress": the one that reaches the device picker last is kept.
- The sign-in step now shows Amazon's "Sorry, we couldn't find that page" page,
  which is the correct page to copy the address from.

## After updating

Restart Home Assistant. New entities for devices you have already picked
appear on their own. Devices that had nothing to show before may now be
listed in the device picker: Settings > Devices & services > Works with Alexa
> Configure.

Installs now come as a release file, `works_with_alexa.zip`, so the
Marketplace can show a download count. Nothing changes for you.

Requires Home Assistant **2026.3.0 or newer**, unchanged. No new Python
requirements.
